## Stay safe

::: danger We will never…
- message you first
- ask for your seed phrase or private key
- ask you to "validate", "sync" or "migrate" your wallet
- run an airdrop that needs you to send SOL first
:::

- **Check the program ID.** Your wallet shows the program a transaction interacts with. For Corium, it should be `CoriumcqGZW3cdnAiyWz6jHHveMUmdrw9RC1KXfMsF8S`.
- **Signing in is a message, not a transaction.** If a "sign-in" asks you to approve a transfer, it isn't us.
- **Check the domain.** The game is only at `corium.so` / `www.corium.so`.

## Reporting a vulnerability

Found a bug in the program or the app? Please email [corium.so@proton.me](mailto:corium.so@proton.me), or see [corium.so/.well-known/security.txt](https://www.corium.so/.well-known/security.txt). Please don't disclose it publicly until we've had a chance to fix it.
